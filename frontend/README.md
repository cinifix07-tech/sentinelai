# Frontend Setup

1. Copy `.env.example` to `.env`.
2. Confirm `VITE_API_URL` points to the backend API.
3. Install dependencies:

```bash
npm install
```

4. Start the dashboard:

```bash
npm run dev
```

Default test accounts after backend seeding:

- `admin@cinifix.com` / `0147`
- `client@cinifix.com` / `0147`
